CHEEZAY DIKHAO - FIREBASE SETUP

1) Authentication > Sign-in method:
   - Google: ENABLED
   - Email/Password: optional
   - Anonymous: NOT REQUIRED for this version. You can disable it.

2) Authentication > Settings > Authorized domains:
   Add:
   - localhost
   - your Vercel domain, e.g. your-project.vercel.app
   Do NOT include https:// in the domain entry.

3) Google login:
   The website now uses Firebase signInWithRedirect instead of popup. This is more reliable on browsers that block popups.

4) Admin:
   Click the Cheezay Dikhao logo 5 times quickly.
   Admin password: nabel3457
   Anonymous Authentication is NOT used by the admin code.

5) Realtime Database:
   Apply database.rules.json in Realtime Database > Rules.

SECURITY NOTE:
The requested admin password is stored in frontend JavaScript, so it is not a secure production admin authentication system. The heroImage path is intentionally writable without Firebase authentication so the requested password-only admin can save without Anonymous Auth. For a real production admin, use Firebase Authentication + security rules/Cloud Functions.
