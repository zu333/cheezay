CHEEZAY DIKHAO - FIREBASE SETUP

1) Firebase Console > Authentication > Sign-in method
   - Email/Password: ENABLED
   - Google: ENABLED
   - Anonymous: NOT REQUIRED

2) Firebase Console > Authentication > Settings > Authorized domains
   Add:
   - localhost
   - your Vercel domain, e.g. cheezay-dikhao.vercel.app
   Do NOT add https:// to the domain.

3) Firebase Console > Realtime Database > Rules
   Import/copy database.rules.json from this ZIP.
   This project uses a password-only admin panel, so the admin's Firebase writes are allowed by these rules.

4) Google Login
   The website now uses signInWithPopup first and redirect as fallback.
   If Google still shows auth/unauthorized-domain, add the exact Vercel hostname to Authorized domains.
   If it shows auth/popup-blocked, allow popups for the site.

5) Admin
   Click the logo 5 times quickly. Password: nabel3457

6) Categories
   Admin > Categories:
   - Category names are loaded from Firebase/local data.
   - Add Category saves immediately.
   - Remove saves immediately.
   - Edit name/key and click Save Categories.
   - Upload category image, it is resized to 300x300 and saved.

7) Products and images are saved under siteSettings/products and siteSettings/categories.
