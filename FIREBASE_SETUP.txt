CHEEZAY DIKHAO - FIREBASE SETUP

1) Authentication > Sign-in method:
   - Google: ENABLED
   - Email/Password: ENABLED
   - Anonymous: NOT REQUIRED (can be disabled).

2) Authentication > Settings > Authorized domains:
   Add your actual Vercel domain, for example: your-project.vercel.app
   Also keep localhost for local testing. Do NOT include https://.

3) Email login:
   Email/Password provider must be enabled. Existing users can log in; the website also includes a Create Account option.

4) Google login:
   Website uses signInWithRedirect. If Google login fails, check Authorized domains and that Google provider is Enabled.

5) Admin:
   Click the Cheezay Dikhao logo 5 times quickly. A full-screen Admin panel opens. Password: nabel3457.
   Anonymous Authentication is NOT used.

6) Realtime Database:
   Apply database.rules.json in Realtime Database > Rules.

IMPORTANT: The Firebase API key in index.html is the exact key supplied for project school-c9633.

SECURITY NOTE:
The requested password-only admin is stored in frontend JavaScript and is not production-grade security. For a real secure admin, use Firebase Authentication/Custom Claims and protected database rules.
