CHEEZAY DIKHAO - FIREBASE SETUP

1) Firebase Console -> project school-c9633
2) Authentication -> Sign-in method -> Email/Password -> Enable.
3) Authentication -> Users -> Add user. This email/password will be used in the website Admin Settings.
4) Realtime Database -> Rules -> paste database.rules.json.
   NOTE: These rules allow ANY authenticated Firebase user to write. For a private production admin,
   change the write rule to an admin email/claim after you create your admin account.
5) Hosting is not required for this version. Vercel can host index.html directly.
6) Admin Settings is at the bottom of the website. Login with the Firebase admin account.
7) Upload image -> set width/height -> Resize Image -> Save Hero to Firebase.
8) The public homepage reads siteSettings/heroImage from Realtime Database.

The Firebase Web config is included in index.html as provided by the owner.
